# TAREK-STOR - متجر طارق الرقمي

متجر إلكتروني متكامل لبيع المنتجات والخدمات الرقمية

## المميزات

- **نظام الهوية**: تسجيل دخول/إنشاء حساب مع رقم تعريفي فريد من 6 أرقام
- **لوحة تحكم**: لوحة إدارة متقدمة للمدير مع حماية بالبريد الإلكتروني
- **نظام المحفظة**: محفظة رقمية لكل مستخدم مع أكواد شحن (Redeem Codes)
- **متعدد اللغات**: دعم كامل للعربية والإنجليزية والفرنسية
- **تحويل العملات**: تحويل تلقائي للأسعار حسب الموقع الجغرافي
- **الفلترة الجغرافية**: تحديد ظهور منتجات لدول معينة
- **إحصائيات شاملة**: زيارات، طلبات، نمو المستخدمين، سجلات المحفظة

## التقنيات

- **Next.js 14** (App Router)
- **TypeScript**
- **Prisma** + SQLite
- **NextAuth.js**
- **Tailwind CSS**

## التشغيل

```bash
# تثبيت الحزم
npm install

# إعداد قاعدة البيانات
cp .env.example .env
npx prisma migrate dev

# تشغيل المشروع
npm run dev
```
